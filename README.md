# riso-graphic

리소그래프 인쇄를 화면에서 흉내 내는 샘플 시트 한 장. 스팟 잉크 두세 통을 한 장에 겹쳐
찍고, 판마다 미세하게 어긋나고, 어떤 면도 완전히 채워지지 않는다.

빌드 도구가 없다. 정적 HTML, ES 모듈, 2D 캔버스가 전부다.

## 실행

ES 모듈은 http 출처가 필요해서 `index.html`을 파일로 여는 것은 동작하지 않는다.

```bash
node serve.mjs
```

`http://localhost:7400`. 포트는 인자나 `PORT` 환경 변수로 바꾼다.

## 인쇄 순서

리소는 CMYK로 섞어 찍지 않는다. 색마다 드럼이 따로 있고, 드럼 수만큼 종이가 통과하며,
섞이는 일은 종이 위에서만 일어난다. `src/poster.js`가 그 순서를 그대로 따른다.

1. **배치** — 화면 전체를 마크 목록으로 한 번에 깔고, 마크마다 어느 드럼이 찍을지 태그한다.
2. **드럼별 통과** — 태그가 맞는 마크만 검정으로 그려 마스크를 만든다.
3. **스크린** — 마스크의 알파를 그레인이 갉아먹는다. 솔리드도 100%가 되지 않는다.
4. **잉크** — 남은 알파를 드럼 색으로 물들인다.
5. **안착** — `multiply`로, 1~2픽셀 어긋난 자리에 얹는다.

노랑이 파랑 위에 곱해지면 초록 말고 갈 곳이 없다. 드럼 두 통으로 세 가지 색이 보이는
이유가 이것이고, 이 샘플이 보여주려는 것도 이것이다.

배치 단계에서 난수를 다 쓰고 그리기 단계에서는 쓰지 않는다. 드럼마다 그리기를 다시
도는데 거기서 난수를 당기면 두 번째 통과가 첫 번째와 다른 그림을 찍는다.

## 다이얼

| 다이얼 | 하는 일 |
| --- | --- |
| NEW SHEET | 새 롤. 같은 숫자는 언제나 같은 장을 찍는다 |
| HEADLINE | 비우면 배색 이름을 따라간다. 글자가 길면 판이 줄어든다 |
| INKS | 배색 아홉 벌. 칩 순서가 드럼 순서다 |
| DRUMS | 2도와 3도. 2도는 마지막 드럼을 뺀 같은 판이다 |
| GRAIN | 스크린이 갉아먹는 양 |
| REGISTER | 판 어긋남, 픽셀 |

설정은 전부 주소에 들어간다. 마음에 드는 장은 링크로 남는다. `N` 새 시트, `S` 저장.

## 파일

| 파일 | 맡은 것 |
| --- | --- |
| `src/rng.js` | 시드 난수와 값 노이즈. 재현성의 뿌리 |
| `src/palette.js` | 잉크 아홉 벌, 종이색, 드럼 수 자르기 |
| `src/grain.js` | 스크린과 종이결 — 리소처럼 보이게 하는 부분 |
| `src/shapes.js` | 유기적 덩어리와 멤피스 장식 |
| `src/poster.js` | 배치와 인쇄 |
| `src/main.js` | 다이얼, 주소, PNG |
| `serve.mjs` | 정적 서버. 모듈 URL에 부팅 도장을 찍어 옛 모듈이 남지 않게 한다 |

## 형태 어휘

두 가족을 섞는 것이 이 스타일이다.

- **유기적** — 블롭, 찢긴 판, 물방울, 잎. 자와 컴퍼스가 닿지 않은 것들
- **멤피스** — 물결, 지그재그, 반짝임, 나선, 마름모. 1980년대식 흩뿌리기

잔글씨는 배색에서 가장 어두운 잉크로만 찍는다. 크림색 종이 위에서 노랑 잔글씨는 읽히지
않는다. 바닥 블록의 흰 글자는 흰 잉크가 아니라 녹아웃이다. 그 자리만 드럼이 찍지 않아
종이가 그대로 드러난 것이라, 블록 자신의 마스크에서 파낸다.
